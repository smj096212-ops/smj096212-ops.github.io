Not another tutorial. A stopwatch.

Most 2048 sites are written for people playing it for the first time. This one isn't. It's built for players who already know the merge rules cold and have moved past "can I reach 2048" to "how fast can I reach 2048." There's no tutorial popup, no move counter, no difficulty setting — just a timer that starts the second you hit Start, and a global leaderboard that only cares about one number: elapsed time for runs that actually finish.

Who this is for

If you've never played 2048, this probably isn't the best place to start — there's no hand-holding here. But if you've already put in the reps and want to see how you stack up against players worldwide, this is exactly the tool for that: reach 2048, get ranked by time, and check the leaderboard beside the board to see who's currently fastest. Only runs that reach 2048 make it onto the leaderboard.
